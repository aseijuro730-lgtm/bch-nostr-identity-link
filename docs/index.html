    How it works
    
    
      
      
    1. Same key, two networks. secp256k1 is the signature curve of both Bitcoin Cash and Nostr.
        One private key derives a BCH address (compressed pubkey → HASH160 → cashaddr) and a Nostr
        pubkey (the x-only BIP340 pubkey). The x-coordinate is identical — the link is provable from
        public data alone.
      2. 
      
    2. Mutual signatures. The BCH key signs the statement as a standard Bitcoin signed-message
        (double-SHA256, ECDSA, recoverable — verifiable in Electron Cash / Paytaca). The Nostr key signs
        the same statement with Schnorr (BIP340, NIP-01 style). Both signatures must verify, and the
        statement must name both identifiers.
      3. 
      
    3. Cross-key mode. Already have a BCH address and a Nostr account on different keys? Import
        both and they mutually attest each other instead. The verifier checks the signatures, not the
        key relationship.
      4. 
      
    4. Zero cost. No transaction is broadcast, no gas, no fee. Verification is offline math.
        Publishing is one optional Nostr event to public relays.
      5. 
      
    5. Why it matters. Paytaca, BCHNostr and the BCH creator economy need Sybil-resistant,
        portable identity: tips, reputation and social graphs that survive any single app dying. A
        cryptographic BCH↔Nostr link is the primitive that makes "I am the same person here and there"
        trustless.
